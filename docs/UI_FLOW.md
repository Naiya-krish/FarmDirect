# UI/UX Screen Flows

## 1. Farmer Journey
1. **Voice Listing Screen:** Tap microphone button, speak in Hindi/Marathi ("कल 200 किलो टमाटर तैयार हैं"), AI auto-extracts crop tags.
2. **Price Discovery Screen:** Displays suggested fair range (e.g., ₹22–₹26/kg), allows total farmer pricing override.

## 2. Buyer Journey
1. **Storefront:** Choose between **Farm Fresh Track** (Harvest post-order, same-day delivery) or **Quick Store Track** (2-hour dispatch for daily staples).
